# Pankaj Kumar — Developer Portfolio

A modern and responsive personal portfolio website showcasing my projects, professional experience, technical skills, and journey as a Software Developer.

## About The Project

This portfolio website represents my work, skills, and professional journey as a Software Developer. It features a modern and responsive user interface with smooth animations and dedicated sections for my projects, experience, technical skills, and contact information.

The goal of this portfolio is to provide a clean and interactive way to explore my work and learn more about my experience in software development.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/pankajkumar1922003-ku/Portfolio.git
```

### 2. Navigate to the project directory

```bash
cd YOUR-REPOSITORY
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```
